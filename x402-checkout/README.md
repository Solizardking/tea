# x402-checkout

Public host for https://checkout.x402.life (Ace / Tangiers fiat checkout).

Deployed on Railway at https://x402-checkout-production.up.railway.app. Local run, service variables, `railway up`, public domain, and webhook URL are in [CHECKOUT.md](./CHECKOUT.md).

```bash
cd x402-checkout
cp .env.example .env
npm install
npm start
npm test
```
