Private AI Gateway (ACI)

OpenAI-compatible gateway for Attested Confidential Inference. Relying parties check:

  1. Gateway attestation report
  2. Provider verification event for the route
  3. Signed receipt binding the response

Unpaid health: gateway GET /health · proxy GET /__x402/health. Chat requires payment or day-pass.

Configure

cp .env.example .env
# KORA_SIGNER_PRIVATE_KEY = base58 64-byte secret (operator host only)
# allowed_spl_paid_tokens must include $CLAWD mint
# price_source = "Mock" for local/dev

Run

# T1 — Kora JSON-RPC (:8080)
./scripts/start-kora.sh

# T2 — facilitator (:3000)
cd facilitator && npm install && npm start

# T3 — payment proxy (:8787)
cd ../x402-proxy-template && npm run dev

Check

curl -s http://127.0.0.1:8080 -H 'content-type: application/json' \
  -H "x-api-key: $KORA_API_KEY" \
  -d '{"jsonrpc":"2.0","id":1,"method":"getConfig","params":{}}'

curl -s http://127.0.0.1:3000/supported
curl -s http://127.0.0.1:8787/__x402/health
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8787/__x402/protected
# expect 402
